# Random Password Generator

 Project Description
A simple Python-based Random Password Generator that creates secure and random passwords based on the user's selected character types.

 Features
- Allows users to choose password length (minimum 8 characters).
- Supports uppercase and lowercase letters.
- Includes numbers and special symbols.
- Allows users to select multiple character types.
- Ensures at least one character from each selected type.
- Generates shuffled random passwords.
- Provides an option to generate multiple passwords.

 Technologies Used
- Python
- Random Module
- String Module

 How to Run
1. Download or clone this repository.
2. Open the Python file.
3. Run the program.
4. Enter the desired password length.
5. Select at least two character types.
6. View your generated password.

 Concepts Used
- Loops
- Conditional Statements
- Exception Handling
- Functions from Python Modules
- Random Selection
- String Manipulation

 Project Objective
To develop a beginner-friendly Python application that generates random passwords and helps users understand basic Python programming concepts.
